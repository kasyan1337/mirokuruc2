# whoami

This website acts as a digital business card, allowing visitors to learn more about me, my writing, and easily access my contact information. Simple, clean, and minimalistic design created with lot of coffee.

## 📂 Project Structure
```
/ (Root)
├── blog/           # File for blogposts
├── pictures/       # Images, icons, and other resources
├── CNAME           # Domain config
├── README.md       # Project documentation
├── index.html      # Main webpage
├── resume.html     # Resume webpage
├── robot.txt       # Web crawlers restricion
├── script.js       # Java scripts
└── style.css       # .css Style
```
